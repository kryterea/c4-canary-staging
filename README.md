# Beacon order intake (fictional)

This repository is test material for Kryterea's assurance checks. Beacon is a fictional company, and this code is not a real system. It implements some of the stories in the Beacon "Epic and User Stories" deliverable, on purpose not all of them and not all correctly, so that a check against the approved stories has something to find.

Run the tests with Node 22.18 or later, which runs TypeScript directly:

```bash
npm test
```

There are no dependencies to install.
